# Understand intent

This skill structures human-in-the-loop LLM workflows. It's aimed at determining what the user wants in the context of a choice to be made, and ensuring the user understands what tradeoffs have been considered.

The core insight here is that we can reliably decide whether to refer to the existing context or ask the developer to refine it, instead of falling back to "agent-driven" unsubstantiated decisionmaking.
